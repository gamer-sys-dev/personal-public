# Personal apps (public)

Small apps for Chade's household, each in its own folder and hosted free on GitHub Pages. This repo is public.

## Hard rule

No personal data in this repo, ever: no names, birth dates, addresses, health details, photos or anything that could identify the family or the pets. Personal notes live in the private repo gamer-sys-dev/personal-private. Apps store the user's own data on their device (localStorage), never in the code.

## Writing rules

- British English. No em or en dashes. No Oxford comma. No AI vocabulary or patterns.
- Short answers on the phone. Push back on weak ideas.

## How to build here

- One folder per app, each with its own short CLAUDE.md for app specific notes.
- Plain HTML, CSS and JavaScript unless there's a strong reason otherwise. No build step, so it works straight from GitHub Pages.
- Must work on Android (Chrome) and iPhone (Safari), including added to the home screen.
- Add each app to the root index.html.
- Push to main when a change is tested and working.
